# Remarks

This file is intentionally neutral until a new run starts.

Use local `runs/current/remarks.md` as the compact high-signal run log for:

- orchestrator-detected stalls, invalid handoffs, and other control-plane
  diagnoses
- CEO unblock interventions and end-of-phase review outcomes
- durable playbook feedback that has already been promoted out of ad hoc
  role-specific notes

Ordinary runtime-role observations, repeated verification results, stale
blocker repetition, and other run-specific notes belong in
`runs/current/notes.md`, role-owned artifacts, or evidence files instead.
