# Change Packet Template

Use this scaffold as the canonical starter for `iterative-change-run` and
`app-only-hotfix` packets.

Required contents:

- `request.md`
- `classification.yaml`
- `impact-manifest.yaml`
- `affected-artifacts.md`
- `affected-candidate-artifacts.md`
- `affected-app-paths.md`
- `reopened-gates.md`
- `role-loads/*.yaml`
- `candidate/artifacts/**`
- `verification/**`
- `evidence/`
- `promotion.yaml`
