# Final Review Pack Template

Use `runs/current/evidence/final/` as the no-code audit pack for the delivered
app.

The Product Manager owns this directory during acceptance and MUST refresh it
as the final review bundle for downstream human or CEO review.

Expected contents include:

- `review-index.md`
- copied high-level product and UX artifacts
- copied screenshot manifests
- copied reference screenshots when previews were captured

This directory should let a reviewer evaluate the app at a high level without
opening implementation files.
