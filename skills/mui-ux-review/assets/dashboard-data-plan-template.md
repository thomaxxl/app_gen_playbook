Examples of strong regions:

- pending approvals
- stale items
- failures or blocked jobs
- assigned work queue
- items needing review today
- critical alerts

## Regions to remove or demote

- vanity metrics with no action path
- duplicate cards
- charts without a next step
- long explanatory text blocks

## Summary design rules

- Keep summary regions short.
- Pair every important metric with either context or an action path.
- Prefer actionable queues over decorative overviews.
