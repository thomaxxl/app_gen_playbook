Leads: Frontend and/or Backend

## Goal

Implement only the approved change scope against the current app baseline.

## Outputs

- app changes in owned subtrees only
- updated tests
- implementation evidence

  references, keep the implementation faithful to those references unless they
  conflict with the input prompt or the business-model / API / rules contract
- Architect integration-review handoff
